# Agentcraft

Agentcraft is an unofficial learning site that teaches people to get real work done with Claude Code, starting with non-developers and leading into advanced developer use.

## Learners and structure

**Learner**:
Anyone using Agentcraft to learn Claude Code, developer or not.
_Avoid_: User, student, customer

**Persona**:
One of the two kinds of Foundations Learner every Foundations Goal must serve: the Knowledge worker and the Aspiring builder.
_Avoid_: User type, audience segment

**Knowledge worker**:
A Persona who works mainly in documents and spreadsheets (marketing, ops, admin, students).
_Avoid_: Office user, non-technical user

**Aspiring builder**:
A Persona who wants to make a site or tool without coding (founders, designers, freelancers).
_Avoid_: Vibe coder, no-coder

**Journey**:
The single route a Learner follows from first contact with AI to advanced Claude Code use, made of Tracks in order.
_Avoid_: Path, course, curriculum (as a name for the whole route)

**Track**:
One stage of the Journey. There are two: the Foundations track and the Advanced track.
_Avoid_: Mode, level, path

**Foundations track**:
The first Track: no code, taught in the Claude Code Desktop app, aimed at non-developers getting their first wins with AI.
_Avoid_: Beginner mode, non-dev path

**Advanced track**:
The second Track: taught in the Terminal, covering real developer workflows.
_Avoid_: Advanced mode, developer path, pro mode

**Skip check**:
A short check that lets a Learner who already has the Foundations capabilities start at the Advanced track.
_Avoid_: Placement test, quiz, level test

**Goal**:
A real outcome a Learner wants (e.g. "automate a weekly report"), used as the way into lessons; Claude Code features are learned on the way to a Goal.
_Avoid_: Use case, topic

**Lesson**:
One unit of teaching inside a Track, built around a Goal. Every Lesson has the same shape: the Capability it unlocks, a Session replay, a Hands-on exercise with its Reference result, and optionally an Explorable.
_Avoid_: Chapter, module (for a single unit)

**Flagship lesson**:
One of the few Advanced track Lessons shipped in v1, each a Session replay of a real developer workflow.
_Avoid_: Featured lesson, preview lesson

**Lens**:
The Claude Code surface a Lesson is taught in (Desktop app or Terminal). Each Track has exactly one Lens.
_Avoid_: Setup, surface, platform (on the site)

**Mode**:
Reserved for Claude Code's own modes (plan mode, permission modes). Never used for parts of Agentcraft.

## Learning experiences

**Session replay**:
A real Claude Code session that the Learner plays from the human's seat: they write or pick the human's messages and answer Claude's requests, and Claude answers them. The signature experience of Agentcraft.
_Avoid_: Transcript, demo, simulation, video

**Off-script reply**:
A Learner message that differs from what the real human wrote. Claude answers it once in character, then the Session replay rejoins the real session.
_Avoid_: Wrong answer, branch

**Live view**:
The panel beside a Session replay showing what the session is doing to the Learner's files or tools as it happens.
_Avoid_: Preview, visualization

**Guide**:
Agentcraft's own on-screen coach character (placeholder name Wren). Speaks beside the conversation, never inside it, and is never a likeness of Claude.
_Avoid_: Mascot, assistant, Clawd, animated Claude

**Steering note**:
The Guide's feedback on a Learner's call, or its explanation of why the human steered or why Claude acted as it did.
_Avoid_: Annotation, comment

**Decision pause**:
A point in a Session replay where the Learner makes the human's call (a reply or a permission answer) before seeing what the real human did.
_Avoid_: Quiz, question

**Hands-on exercise**:
An exercise the Learner runs in their own Claude Code from a ready prompt, then compares with a Reference result.
_Avoid_: Simulated terminal, sandbox, playground

**Reference result**:
Agentcraft's annotated outcome for a Hands-on exercise, used for comparison.
_Avoid_: Solution, answer key

**Explorable**:
An interactive diagram showing how the agent behaves (agent loop, context window, permissions) by letting the Learner change state.
_Avoid_: Animation, visualization, simulator

## Progress and trust

**Capability**:
A concrete thing a Learner can now do with Claude Code, stated as "You can now…".
_Avoid_: Badge, achievement, XP

**Capability map**:
The view of all Capabilities in the Journey, showing which ones the Learner has gained. It is the only progress display.
_Avoid_: Dashboard, progress bar, streak

**Verification stamp**:
The note on a Lesson saying which Claude Code version it was checked against and on what date.
_Avoid_: Last updated, version badge
