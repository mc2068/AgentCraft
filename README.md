# Agentcraft

**An unofficial guide to Claude Code**, for developers and non-developers.

Agentcraft is an independent learning site. It is not affiliated with, endorsed by, or sponsored by Anthropic. "Claude" and "Claude Code" are trademarks of Anthropic.

## How this is being built

Agentcraft is planned and built with Claude Code, in the open:

- **The plan**: [the map](https://github.com/mc2068/AgentCraft/issues/1) and its tickets in Issues.
- **The decisions**: [`docs/adr/`](docs/adr/) records each hard-to-reverse choice and its trade-off.
- **The spec**: [`docs/spec/`](docs/spec/) covers the content model, architecture, recording and how this repo proves the work.
- **The research and prototypes**: [`docs/research/`](docs/research/) and [`prototypes/`](prototypes/).
