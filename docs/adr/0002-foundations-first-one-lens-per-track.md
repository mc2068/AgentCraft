# Foundations first, one Lens per Track

Although the site doubles as interview proof for developer roles, v1 leads with non-developers: one Journey where the Foundations track (Desktop app, no code) is complete at launch and the Advanced track (Terminal) ships only 2-3 flagship Lessons, each a Session replay of a real developer workflow. Developers reach Advanced through a Skip check. Each Track is taught in exactly one Lens, so v1 has no setup switcher; this halves screenshot upkeep in a tool that ships ~27 releases a month.

## Considered Options

- Developer path complete first, non-developer starter track (the original charting decision): rejected, because the biggest unmet gap is an on-ramp for non-developers.
- Setup switcher across Desktop, Web, VS Code and Terminal: deferred, because every Lesson multiplies into up to 12 variants to keep current.
