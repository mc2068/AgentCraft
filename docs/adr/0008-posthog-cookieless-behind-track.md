# Analytics: PostHog in cookieless mode, behind a typed track()

We use PostHog Cloud (free plan, EU) in `cookieless_mode: 'always'` for page views, a fixed list of Learner events and real-visitor Core Web Vitals. We chose it over Umami Cloud and Vercel Web Analytics because its free plan shows LCP, INP and CLS separately and allows custom events; Vercel's free tiers do neither, and Umami's free plan was unclear on custom events. Cookieless means no cookie banner and no personal data. The cost is a large script (about 130 kB gzipped), so it loads only after the page has shown, when the browser is idle, with its own size budget; if that hurts Lighthouse scores we switch to `posthog-js-lite` (27 kB) behind the same `track()`. All events go through one typed `track()` in `lib/analytics`, so the event list cannot carry free text and the tool can be swapped in one place. Details in `docs/spec/analytics-and-feedback.md`.
