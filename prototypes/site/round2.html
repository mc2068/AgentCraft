Sort and rename files

About 12 minutesDesktop appChecked with Claude Code 2.1.3xx · 24 Nov 2026
After this lesson: you can ask Claude to organise a folder, set limits, and check before anything moves.

Your Downloads folder is full and you can't find anything. In this replay you take the human's seat in a real session: you ask, you set limits, and you decide what Claude is allowed to do.

Field notes

  1. Say which folder and how to sort it.
  2. Set limits before anything moves.
  3. "Show me the list first" costs ten seconds and catches mistakes.
  4. Nothing was deleted, so every step can be undone.
